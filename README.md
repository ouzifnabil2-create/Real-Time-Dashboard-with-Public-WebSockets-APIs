 📈 Real-Time Crypto & Market Dashboard

A modern, fast, and responsive real-time cryptocurrency dashboard built using vanilla Web technologies, high-frequency WebSockets, and Chart.js.

🚀 Features

⚡ Real-Time Data Streaming: Direct WebSocket connection (via Binance API) for low-latency live price feeds.

📊 Dynamic Interactive Chart: Real-time updating line chart powered by Chart.js to track price fluctuations.

🎨 Modern Dark Mode Interface: Sleek UI designed with dynamic visual feedback (flashing green/red price indicators on change).

📱 Fully Responsive Layout: Grid and Flexbox implementation optimized for desktop, tablet, and mobile displays.

🔀 Multi-Currency Support: Switch seamlessly between top cryptocurrency trading pairs (e.g., BTC/USDT, ETH/USDT, SOL/USDT).

🔄 Connection State Management: Automatic reconnection handling and live status indicators (Connected / Reconnecting).

🛠️ Tech Stack

HTML5: Semantic web markup and layout structure.

CSS3: Custom variables, Flexbox, CSS Grid, and custom keyframe animations for visual price feedback.

JavaScript (Vanilla ES6+): Native WebSocket management, dynamic DOM manipulation, and chart lifecycle state logic.

Chart.js (v4.x): High-performance canvas charting library for real-time data rendering.

📁 Project Structure

├── index.html       # Primary HTML layout
├── styles.css       # UI styling, dark theme, and animation keyframes
├── app.js           # Main application script (WebSocket & Chart.js logic)
└── README.md        # Project documentation
